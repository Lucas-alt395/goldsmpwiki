# Regels voor Oorlogen

## Stappen bij oorlog:
- 1. Meld het bij lucasbed/.LucasBED00
- 2. Wanneer hij het weet, moeten beide landen de TNT protection uitzetten. Als je niet weet hoe dat moet, doet de server admin dat.
- 3. Beide landen moeten naar lucasbed/.LucasBED00 dat ze klaar staan, daarna ontvang je een berichtje van lucasbed/.LucasBED00 dat de andere ook klaar is.
- 4. AANVALLUH!
